# Noslēguma mini-projekts

**Mērķis:** izveidot nelielu, patstāvīgi palaižamu Python programmu, kas atrisina saprotamu praktisku problēmu. Nepieciešams **skaidrs rezultāts**, nevis obligāti daudz koda vai ārējās bibliotēkas.

## Ieteiktie varianti

1. **Izdevumu kopsavilkums.** Nolasa [expenses.csv](../datasets/expenses.csv), aprēķina kopējo summu un summas pa kategorijām.
2. **Tekstu analizators.** Nolasa UTF-8 teksta failu un saskaita rindas, vārdus vai biežākos vārdus.
3. **Uzdevumu saraksts.** Pievieno un apskata uzdevumus, saglabā tos JSON vai SQLite (atkarībā no apgūtā līmeņa).

Var izvēlēties savu ideju, ja to iespējams droši demonstrēt bez paroļu vai privātu datu atklāšanas.

## Ieteiktā gaita

- Līdz 5. nodarbībai: izvēlies problēmu un izdomā, kāda būs ievade/izvade.
- 6.–9. nodarbība: uzbūvē mazāko strādājošo versiju, pēc vēlēšanās papildini ar datnēm/API.
- 10.–11. nodarbība: pārbaudi kļūdas gadījumus, sakārto programmu un sagatavo demonstrāciju.
- 12. nodarbība: parādi programmu un izskaidro galvenos lēmumus.

## Demonstrācijas kontrolsaraksts

- Kādu problēmu programma risina?
- Kā to palaist ar komandu?
- Kādu ievadi tā pieņem?
- Kāds ir rezultāts? Parādi vismaz divus piemērus.
- Kādu kļūdas gadījumu tu pārbaudīji?
- Kuru vienu lietu tu uzlabotu nākamajā versijā?
