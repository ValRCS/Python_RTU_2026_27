# Materiālu papildināšanas noteikumi

- Pievieno studentam saprotamu README attiecīgās nodarbības mapē ar priekšzināšanām, mērķiem, komandām un pārbaudes piemēru.
- Saglabā piemērus mazos, izpildāmos `.py` failos, kas neprasa ārējus pakotņu instalējumus bez skaidra pamatojuma.
- Ja uzdevums izmanto ārēju API, atsevišķi apraksti atkarības, datu avotu un rezervē nodrošini lokālu JSON/CSV paraugu.
- Pievieno tikai licencētus vai pašu sagatavotus datus; nepublicē personas informāciju, piekļuves datus, tokenus vai studentu darbus bez atļaujas.
- Nenosauc jaunu failu tikai pēc nodarbības datuma; nodarbības saturs paliek atkārtoti izmantojams. Konkrētais kurss tiek aprakstīts `cohorts/`.
- Neaizstāj vēsturiskā [2024/25 repozitorija](https://github.com/ValRCS/Python_RTU_2024_25) saturu bez atsevišķas migrācijas un pārbaudes.

**Kvalitātes minimums:** instrukcijā dotās komandas darbojas, saites norāda uz esošiem failiem, piemēriem ir saprotama ievade/izvade, un jaunas atkarības ir dokumentētas.
