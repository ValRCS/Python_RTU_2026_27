# Dati praktiskajiem uzdevumiem

Šeit glabājam mazus piemēru datu failus, kurus iespējams analizēt bez piekļuves ārējiem servisiem.

- [expenses.csv](expenses.csv) — izdomāti izdevumi ar galveni un desmit ierakstiem; summas izmantotas ar punktu kā decimālatdalītāju, komats ir CSV lauku atdalītājs.

**Svarīgi:** izmanto tikai fiktīvus vai publiskus datus. Neievieto personas datus vai sensitīvus darba dokumentus. Datu failiem pievieno kodējumu, kolonnu aprakstus un avota informāciju, ja tas nav mākslīgs piemērs.
