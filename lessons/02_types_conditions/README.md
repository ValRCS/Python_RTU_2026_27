# 2. nodarbība — Datu tipi, operatori un nosacījumi

**Statuss:** plāns; pilnais konspekts un programmēšanas piemēri tiks papildināti pirms nodarbības. Šis fails **nenozīmē**, ka visi minētie uzdevumi jau ir sagatavoti.

## Sasniedzamais rezultāts

Atšķirt int, float, str un bool; lietot salīdzināšanas un loģiskos operatorus; izveidot if/elif/else zarojumu.

## Temati

- int
- float
- str
- bool
- aritmētika
- salīdzinājumi
- if/elif/else

## Ierosinātais praktiskais darbs

Izveidot cenu/atlaides kalkulatoru un temperatūras ieteikumu programmu; izmēģināt nekorektu ievadi.

## Pārbaudi, vai saprasts
