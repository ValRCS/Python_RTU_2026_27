# 1. nodarbība — Python ievads un pirmā programma

**Statuss:** sākotnējais materiāls pieejams · **2026. gada rudens:** 12. novembris, 17:45–21:40.

## Sasniedzamie rezultāti

- Izskaidrot atšķirību starp Python interpretatoru, avota failu un koda redaktoru.
- Pārbaudīt Python instalāciju un patstāvīgi palaist `.py` failu.
- Izmantot `print()`, vienkāršus mainīgos un aritmētiskus izteicienus.
- Izmantot `input()`; apzināties, ka ievades rezultāts ir `str`.
- Nolasīt vienkāršas kļūdas un veiksmīgi izlabot programmu.

## Pirms nodarbības

[Instalē un pārbaudi Python](../../setup/README.md). Git nav obligāts: var lejupielādēt repozitoriju ZIP formātā.

## Nodarbības darba gaita

1. Python un programmēšanas jēdzieni; interaktīvā konsole.
2. `print("Sveiki, Python!")` un aritmētika.
3. Darbs ar `.py` failiem, saglabāšana, atkārtota palaišana.
4. Mainīgie, virknes un skaitļi; `type()` demonstrācija.
5. `input()` un tipu pārveidošana.
6. Praktiski uzdevumi un kļūdu analīze.

## Faili, kurus palaist

- [hello.py](hello.py) — pirmais pilnais piemērs bez ievades.
- [age_calculator.py](age_calculator.py) — vārds, vecums un aprēķins.
- [temperature_converter.py](temperature_converter.py) — neliela temperatūras pārvēršanas programma.

Piemēram, no repozitorija saknes:
```bash
python lessons/01_getting_started/hello.py
```
macOS/Linux gadījumā lieto `python3`, bet dažās Windows instalācijās `py`.
