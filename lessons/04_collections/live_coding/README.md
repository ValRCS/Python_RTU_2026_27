# 4. nodarbība — izvērstie dzīvās programmēšanas piemēri

Papildina piecus īsos pamata skriptus. Atver VS Code un demonstrē pa blokiem; nav jāizpilda visi piemēri nodarbībā. Katrā blokā vispirms prognozē rezultātu, tad palaid, maini datus un apspried. Visi faili ir publiski un paredzēti Python 3 bez ārējām pakotnēm.

| Fails | Demonstrācija | Prioritāte |
| --- | --- | --- |
| [01_lists_live.py](01_lists_live.py) | Indeksi, šķēlumi, mutācija, kārtošana | Pamati; aliasing papildus |
| [02_list_processing_live.py](02_list_processing_live.py) | Skaitļi, filtrēšana, jauna saraksta veidošana | Pamati; ievade un comprehension papildus |
| [03_split_join_live.py](03_split_join_live.py) | Atdalītāji, tīrīšana, skaitļu pārveidošana | Pamati |
| [04_dictionaries_live.py](04_dictionaries_live.py) | Atslēgas, vērtības, pāri, atjaunināšana | Pamati; update/pop papildus |
| [05_frequency_analysis_live.py](05_frequency_analysis_live.py) | Biežumi, izsekošana, simboli | Pamati; paplašinājumi papildus |
| [06_shopping_basket_live.py](06_shopping_basket_live.py) | Daudzumi un zināmo cenu summa | Demonstrācija vai apspriede |
| [07_tuples_live.py](07_tuples_live.py) | Korteži un izpakošana | Īss ievads |
| [08_sets_bonus.py](08_sets_bonus.py) | Unikālums, piederība, kopu algebra | Pirmais bloks visiem, pārējais papildus |
| [09_debugging_collections.py](09_debugging_collections.py) | Izņēmumi un loģiskās kļūdas | Izvēlies atbilstoši jautājumiem |

No repozitorija saknes, piemēram:

```powershell
python lessons/04_collections/live_coding/01_lists_live.py
python lessons/04_collections/live_coding/02_list_processing_live.py
python lessons/04_collections/live_coding/02_list_processing_live.py --input
```

macOS/Linux: vajadzības gadījumā lieto python3. Bez --input visi skripti ir neinteraktīvi. sys.argv, assert un comprehension ir demonstrāciju tehniski/papildu elementi, nevis šīs nodarbības obligātie rezultāti.
