## Sasniedzamie rezultāti
- Atšķirt Python objektu un JSON tekstu; izmantot load/loads/dump/dumps.
- Izveidot venv, instalēt ārēju pakotni ar pip, izvēlēties pareizo interpretatoru.
- Izpildīt notebook šūnas secīgi, restartēt kodolu, strādāt lokāli vai Colab.
- Attēlot iepriekšējās nodarbības kategoriju summas ar matplotlib.

## Palaide
Skriptiem atver repozitorija saknes mapi, piemēram, `python lessons/07_notebooks_json/02_json_files.py`. JSON skriptiem vajadzīga tikai standarta bibliotēka. Grafikam un lokālam notebook aktivizētā virtuālajā vidē: `python -m pip install -r lessons/07_notebooks_json/requirements.txt`. VS Code izvēlies .venv interpretatoru/kodolu. Colab lietotāji var atvērt notebook tieši; piemēru dati iekļauti šūnās. Lokāla grafika piemērs izmanto matplotlib, pandas ir tikai papildu tēma.
