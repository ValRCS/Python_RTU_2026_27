# 1. nodarbības uzdevumi

Katram uzdevumam izveido **atsevišķu `.py` failu** savā datorā. Pirms tam palaid [pirmos piemērus](../../lessons/01_getting_started/README.md).

## 1. Sveiciens (iesildīšanās)
Izvadi `Sveiki, Python!` un savu vārdu. Izmaini programmu tā, lai vārdu var ievadīt ar `input()`.

## 2. Vecums un 100 gadi
Pieprasi vārdu un vecumu. Izrēķini, pēc cik gadiem cilvēkam būs 100 gadi. Izmēģini ievadi `30`, sagaidāmais aprēķins — `70`. Papildu: iegūsti pašreizējo gadu ar `datetime`, nevis ieraksti to manuāli.

## 3. Telpas tilpums
Pieprasi telpas **garumu, platumu, augstumu** metros; izrēķini tilpumu kubikmetros. Piemērs: 4 × 3 × 2.5 = **30.0 m³**. Atceries `float()`.

## 4. Celsijs → Fārenheits
Pieprasi temperatūru pēc Celsija un izmanto formulu `F = C * 9/5 + 32`. Piemēri: 0 °C → 32 °F; 100 °C → 212 °F; -40 °C → -40 °F.

## Pašpārbaude
- Vai programma ir saglabāta `.py` failā un palaižas atkārtoti?
- Vai vari paskaidrot, kāpēc `input()` rezultātu dažkārt pārveido ar `int()` vai `float()`?
- Kas notiek, ja ievadi nevis skaitli, bet tekstu? Tas vēl nav jāizlabo.

**Papildu uzdevums pieredzējušākiem:** ievadi pārbaudīt un kļūdas gadījumā atjaunot pieprasījumu. Tas pārsniedz 1. nodarbības obligāto apjomu.
