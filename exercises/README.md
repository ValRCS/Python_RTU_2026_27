# Praktiskie uzdevumi

Sāc ar [1. nodarbības uzdevumiem](01_getting_started/README.md). Turpmāko nodarbību uzdevumi tiks pievienoti līdz ar lekciju materiāliem.

**Darba princips:** katru uzdevumu vispirms izpildi pats, tad izmēģini vēl vismaz vienu ievadi, kas atšķiras no piemēra. Saglabā savu risinājumu `.py` failā.

**Risinājumu publiskošana:** pasniedzēja atsauces risinājumi, vērtējumi un individuālie studentu dati netiks glabāti šeit. Repozitorijs paredzēts mācību piemēriem un uzdevumu aprakstiem.
