# Pasniedzēja organizatoriskās piezīmes (publiska sadaļa)

Šajā repozitorijā tiek uzturēta atkārtoti izmantojama 12 nodarbību secība. Aktuālās rudens grupas datumi ir [cohorts/2026_fall.md](../cohorts/2026_fall.md), bet nākamam kursam jāizveido jauns grafika fails.

## Satura izstrādes principi

- **Pirmie 6 temati:** lokālā Python vide, izpildāmi īsi `.py` piemēri un standarta bibliotēka.
- **Pēc pamatiem:** Google Colab/Jupyter pēc vajadzības, JSON, HTTP, datu apstrāde.
- **Katrā lekcijā:** sasniedzamais rezultāts, īss piemērs, patstāvīgs uzdevums, kļūdu demonstrācija un pašpārbaude.
- **Atdalīt:** sākuma kodu, atsauces risinājumus un iepriekšējo gadu arhīvu. Nenosūtīt studentiem nesakārtotus vairākus alternatīvus variantus kā vienīgo mācību materiālu.
- **Nekāda obligāta Git vai pip instalēšana 1. dienā.** Pirmās stundas panākumu kritērijs ir patstāvīga programmas palaišana.
- **Dalīt slodzi:** OOP, Selenium un pilns Django projekts nav obligāta 12 lekciju sākumkursa minimuma daļa. Flask demonstrācija var būt ievads, nevis pilnvērtīga web izstrādes kompetence.

## Vēl izdarāmais (nepabeigtās lietas)

1. Detalizēti sagatavot 2.–6. nodarbības piemērus un uzdevumus.
2. Nošķirt droši demonstrējamu HTML paraugu no dzīvu vietņu skrāpēšanas.
3. Sagatavot mazu, atkārtojamu JSON/API notebook, pārbaudīt ārējās API pieejamību un nodrošināt lokālu JSON rezerves piemēru.
4. Paplašināt SQLite uzdevumu ar parametrizētu SQL, vienkāršiem datu integritātes principiem un kļūdām.
5. Pārbaudīt Flask demonstrāciju tikai lokālā adresē; nepalaist publiski pieejamu izstrādes serveri.
6. Izstrādāt vienkāršu testu piemēru ar `unittest` (standarta bibliotēka).
7. Saskaņot noslēguma projekta vērtēšanu ar kursa organizatoru.
