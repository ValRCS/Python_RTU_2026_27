# Python uzstādīšana — macOS

1. Izmanto oficiālo instalētāju vietnē https://www.python.org/downloads/macos/.
2. Atver **Terminal** un pārbaudi:
   ```bash
   python3 --version
   ```
3. Lejupielādē kursa repozitoriju ZIP formātā, izpako un terminālī pārej uz izpakoto mapi.
4. Palaid:
   ```bash
   python3 lessons/01_getting_started/hello.py
   ```
5. Vari izmantot Python komplektā pieejamo IDLE vai izvēlēties VS Code ar Python paplašinājumu.

macOS bieži izmanto komandu `python3`, nevis `python`. Svarīgi pārbaudīt to pašu interpretatoru, ar kuru vēlāk palaidīsi programmas. Neizmaini sistēmas Python instalāciju tikai kursa dēļ.
