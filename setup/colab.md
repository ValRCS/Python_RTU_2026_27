# Google Colab vēlākajām nodarbībām

[Google Colab](https://colab.research.google.com/) izpilda Jupyter notebook šūnas attālinātā vidē. Tas ir noderīgi JSON, API, datu apstrādes un grafiku nodarbībās.

1. Atver Colab savā pārlūkā, izmantojot Google kontu.
2. Izveido jaunu notebook un ieraksti `print("Sveiki no Colab!")`.
3. Palaid šūnu un salīdzini ar lokāli palaistu `.py` failu.
4. Ja notebook atrodas GitHub repozitorijā, Colab var izmantot **File → Open notebook → GitHub** vai lejupielādētu `.ipynb` failu.
5. Saglabā savu darbu Google Drive vai lejupielādē `.ipynb` failu.

**Svarīgi:**
- Colab vide darbojas citā datorā un atvienojoties var pazust sesijas faili, mainīgie un uzstādītās pakotnes.
- Vietējais `C:\...` vai `/home/...` ceļš parasti nav pieejams Colab. Darbam ar failiem izmanto augšupielādi vai piesaisti Drive.
- Neievieto publiskā notebook paroles vai API atslēgas. Ja vēlāk vajadzīga piekļuve servisam, izmanto piemērotu noslēpumu pārvaldību.

**Secinājums:** lokālais Python ir primārais kurss sākuma posmā; Colab ir papildu rīks, nevis Python instalācijas mācību aizstājējs.
