2. for un range()

for pāriet cauri vērtību secībai. range(stop) sāk ar 0 un apstājas pirms stop. Pilnais pieraksts ir range(start, stop, step), kur stop ir neiekļauta robeža.

Python 3
for n in range(1, 6):
    print(n)  # no 1 līdz 5

total = 0
for n in range(1, 6):
    total += n
print("Summa:", total)  # 15

total ir akumulators — mainīgais, kurā saglabājam daļējo rezultātu. total += n ir tas pats, kas total = total + n.

3. while — cikls ar nosacījumu

while atkārto darbības, kamēr nosacījums ir True. Ja nosacījumu nemaina, cikls var kļūt bezgalīgs. Ilgstošu programmu terminālī var apturēt ar Ctrl+C.

Python 3
i = 0
while i < 4:
    print(i)
    i += 1
print("Pabeigts")

while izpildes pēdas

Katrs klikšķis izpilda vienu simulētās programmas soli.

Python 3
count = 0
while True:
    text = input("Ievadi tekstu (beigt — iziet): ")
    if text.strip().lower() == "beigt":
        break
    count += 1
print("Ievadītās rindas:", count)

Komanda beigt darbojas kā pārtraukšanas signāls (sentinel), tāpēc mums nav iepriekš jāzina atkārtojumu skaits.

5. Kļūdu apstrāde ciklos — try/except

Otrajā nodarbībā sastapām ValueError pie int("abc"). Izmantojot try/except while ciklā, pēc kļūdainas ievades varam jautāt vēlreiz, nevis pārtraukt programmu.

Python 3
while True:
    text = input("Ievadi nenegatīvu veselu skaitli: ")
    try:
        number = int(text)
    except ValueError:
        print("Nederīga ievade. Mēģini vēlreiz!")
        continue

    if number < 0:
        print("Skaitlim jābūt nenegatīvam.")
        continue
    break

print("Paldies! Ievadītais skaitlis:", number)

Izmēģini secīgi: abc → ValueError tiek apstrādāts; -2 → pārvēršana izdodas, bet if noraida negatīvu skaitli; 5 → break iziet no cikla.

continue atsāk nākamo iterāciju, bet break beidz ciklu. Iespējami dažādi kļūdu veidi — noķeram paredzamo ValueError, nevis izmantojam vispārīgu except:, kas var slēpt citas problēmas.

Papildus: iziešana ar komandu q

Iziešanas komandu pārbaudi pirms skaitļa pārvēršanas; citādi int("q") izraisīs kļūdu.

Python 3
while True:
    text = input("Skaitlis vai q: ").strip().lower()
    if text == "q":
        print("Beidzam darbu.")
        break
    try:
        number = int(text)
    except ValueError:
        print("Ievadi veselu skaitli.")
        continue
    print("Kvadrāts:", number ** 2)
Padziļināti: ValueError un ZeroDivisionError

Šis ir izvēles piemērs: kļūdīties var gan ievadot skaitli, gan dalot ar nulli. Plašāka izņēmumu apstrāde nav obligāta.

Python 3
while True:
    try:
        a = float(input("Dalāmais: "))
        b = float(input("Dalītājs: "))
        print("Rezultāts:", a / b)
        break
    except ValueError:
        print("Ievadi skaitļus, piemēram, 2.5.")
    except ZeroDivisionError:
        print("Ar nulli dalīt nedrīkst.")

6. Virknes kā secības

str ir nemaināma rakstzīmju secība. Ar for char in text var apskatīt katru rakstzīmi, ar len(text) — virknes garumu. Python viena rakstzīme arī ir str; atsevišķa char tipa nav.

Python 3
text = "Rīga"
print(len(text))  # 4
for char in text:
    print(char)

vowels = "aāeēiīouū"
count = 0
for char in text.lower():
    if char in vowels:
        count += 1
print(count)  # 2

Unicode: latviešu burti ā, ē, ī, ū tiek apstrādāti kā rakstzīmes. len(str) skaita Unicode koda punktus, kas dažkārt atšķiras no vizuāli uztveramu simbolu skaita.

7. Indeksi, šķēlumi, nemaināmība

Pirmais indekss ir 0, pēdējais — -1. Šķēlums text[start:stop] satur sākumu, bet ne beigas. text[::-1] apgriež secību.

Python 3
word = "Python"
print(word[0])     # P
print(word[-1])    # n
print(word[1:4])   # yth
print(word[::-1])  # nohtyP

# word[0] = "J"  # TypeError
new_word = "J" + word[1:]  # Jython

9. Patstāvīgā prakse (20:25–21:05)

Raksti un palaid katru programmu atsevišķā .py failā. Pirmie trīs uzdevumi ir pamata līmenis; pēdējie divi — izaicinājumi. Risinājumu atver pēc paša mēģinājuma. Atkārtotu skaitļu ievadi pēc kļūdas vari veidot ar 5. sadaļas try/except ValueError paraugu; pirmajos trīs uzdevumos tas ir papildu izaicinājums.

1. Skaitļu summa

Ievadi nenegatīvu n un ar for/range aprēķini summu no 1 līdz n. Pārbaudi n=0 → 0, n=1 → 1, n=10 → 55. Papildus: pāra skaitļu summa un kļūdainas ievades atkārtošana.

Padoms

Izmanto total=0 un total += n.

Viens iespējamais risinājums
Python 3
n = int(input("n: "))
if n < 0:
    print("Nederīgs n")
else:
    total = 0
    for number in range(1, n + 1):
        total += number
    print("Summa:", total)

4. Skaitļa minēšanas spēle (izaicinājums)

Slepenais skaitlis 7; maksimums pieci mēģinājumi. Pasaki Par mazu/Par lielu. Pie pareizas atbildes pārtrauc ciklu. Papildus: nederīga ievade nepatērē vienu no pieciem derīgiem minējumiem.

Padoms

Izmanto for range(1, 6), if/elif/else, break.

Viens iespējamais risinājums
Python 3
secret = 7
guessed = False
for attempt in range(1, 6):
    guess = int(input(f"{attempt}. minējums: "))
    if guess == secret:
        print("Uzminēji!")
        guessed = True
        break
    elif guess < secret:
        print("Par mazu")
    else:
        print("Par lielu")
if not guessed:
    print("Mēģinājumi beidzās; skaitlis bija", secret)

5. Palindroms (izaicinājums)

Pārbaudi, vai teksts lasāms abos virzienos. Ignorē reģistru un atstarpes. Testi: aka, Python, A ka. Papildus: pārbaudi palindromu ar ciklu, nevis tikai [::-1].

Padoms

Lieto lower(), replace(' ', '') un [::-1].

Viens iespējamais risinājums
Python 3
text = input("Teksts: ")
normalized = text.lower().replace(" ", "")
if normalized == normalized[::-1]:
    print("Palindroms")
else:
    print("Nav palindroms")
