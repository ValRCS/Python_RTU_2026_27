3. JSON un Python: serializācija
Serializācija pārveido Python datu struktūru apmaiņas formātā. Deserializācija atjauno Python struktūru no JSON teksta. json ir standarta bibliotēkas modulis — pip nav nepieciešams.
Python 3
import json

city = {"nosaukums": "Rīga", "galvaspilsēta": True, "piezīme": None}
text = json.dumps(city, ensure_ascii=False, indent=4)
print(text)
data = json.loads(text)
print(data["nosaukums"], type(data))
FunkcijaVirziens
json.dumps(obj)Python → str
json.loads(text)str → Python
json.dump(obj, file)Python → fails
json.load(file)fails → Python
Python 3
import json
text = '{"city": "Rīga", "active": true}'
print(type(text))
data = json.loads(text)
print(type(data))
print(data["active"])

4. JSON lasīšana un rakstīšana
Atver UTF-8 failu ar with, izmanto json.load vai json.dump. Kursa JSON datiem skaitliskā summa jau ir skaitlis, atšķirībā no CSV lauka.
Python 3
import json
from pathlib import Path

with open("datasets/expenses.json", encoding="utf-8") as file:
    expenses = json.load(file)

food = []
for row in expenses:
    if row["category"] == "food":
        food.append(row)

Path("output").mkdir(exist_ok=True)
with open("output/food.json", "w", encoding="utf-8") as file:
    json.dump(food, file, ensure_ascii=False, indent=2)
print(f"Pārtika: {sum(row['amount_eur'] for row in food):.2f} EUR")
Pārtika: 13.50 EUR

8. Pirmā datu vizualizācija
Matplotlib ir ārēja bibliotēka. Pēc instalēšanas importē pyplot. Izmanto 6. nodarbības vārdnīcu; no JSON datiem iegūsti kategorijas un summas, nevis pārraksti tās ar roku.
Python 3
import json
import matplotlib.pyplot as plt

with open("datasets/expenses.json", encoding="utf-8") as file:
    expenses = json.load(file)
totals = {}
for row in expenses:
    category = row["category"]
    totals[category] = totals.get(category, 0.0) + row["amount_eur"]

plt.bar(list(totals), list(totals.values()))
plt.title("Izdevumi pa kategorijām")
plt.ylabel("EUR")
plt.tight_layout()
plt.show()
