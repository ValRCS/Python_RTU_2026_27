Nosacījumi un Būla loģika

Iemācies salīdzināt vērtības, apvienot nosacījumus un vadīt programmas izpildi ar if, elif un else.

2. Salīdzināšana un bool

Salīdzinājuma rezultāts ir True vai False. == salīdzina, bet = piešķir vērtību.

Python 3
x = 12
print(x > 10)    # True
print(x == 12)   # True
print(x != 12)   # False
print(type(x > 10))  # <class 'bool'>

Operatori: == vienāds; != nav vienāds; <, >, <=, >= — lieluma salīdzinājumi.

Uzmanību: input() atgriež str. Skaitliskam salīdzinājumam vispirms izmanto int() vai float().

Ko izvada print(5 == 5)?

Ko izvada print(7 != 7)?

Ko izvada print(3 <= 3)?

Ko izvada print('5' == 5)?

3. Būla algebra: and, or, not

and prasa abus patiesus nosacījumus, or — vismaz vienu, not apgriež patiesumvērtību. Prioritāte: not, tad and, tad or.

Python 3
vecums = 20
ir_students = True
print(vecums >= 18 and ir_students)
print(vecums < 18 or ir_students)
print(not ir_students)

Īssavienojums: and neizvērtē labo operandu, ja kreisais ir aplams; or neizvērtē labo, ja kreisais ir patiess.

Ko izvada print(True and False)?

Ko izvada print(False or True)?

Ko izvada print(not (3 > 2))?

4. if, elif, else

if pārbauda nosacījumu; elif pārbauda nākamo tikai tad, ja iepriekšējais nav izpildījies; else darbojas, ja neviens iepriekšējais nav patiess. Bloku nosaka atkāpe.

Python 3
punkti = int(input('Punkti: '))
if punkti >= 90:
    print('Izcili')
elif punkti >= 60:
    print('Ieskaitīts')
else:
    print('Jāmācās vēl')

Izpildes secība: Python izvēlas pirmo patieso if/elif zaru. else ir neobligāts. Atkāpei jābūt konsekventai (parasti 4 atstarpes).

Ja x = 8 un if x > 5: print('Jā'), kas tiek izvadīts?

Ja x = 5 un if x > 5: print('A') else: print('B'), ko izvada?

Ja x = 10, if x > 0: print('A') elif x > 5: print('B'), ko izvada?

Kas Python nosaka if bloka robežas?

5. Salikti un ligzdoti nosacījumi

Apvieno vairākus salīdzinājumus. Pievērs uzmanību robežvērtībām, and/or atšķirībai un īssavienojuma izvērtēšanai.

Python 3
vecums = int(input('Vecums: '))
if 0 <= vecums < 18:
    print('Nepilngadīgs')
elif 18 <= vecums < 65:
    print('Pieaugušais')
elif vecums >= 65:
    print('Seniors')
else:
    print('Nederīgs vecums')

6. Patstāvīgā prakse (20:25–21:05)

Raksti un palaid katru programmu atsevišķā .py failā. Sāc ar pirmajiem trim uzdevumiem; pēdējie divi ir izaicinājumi. Risinājumu atver tikai pēc sava mēģinājuma.

1. Pozitīvs, negatīvs vai nulle

Ievadi veselu skaitli un izdrukā tā zīmi. Pārbaudi -4, 0 un 7.

Padoms

Izmanto if, elif un else.

Viens iespējamais risinājums
Python 3
skaitlis = int(input('Skaitlis: '))
if skaitlis > 0:
    print('Pozitīvs')
elif skaitlis < 0:
    print('Negatīvs')
else:
    print('Nulle')

2. Pilngadības pārbaude

Ievadi vecumu. Ja vecums ir negatīvs, izdrukā kļūdas paziņojumu; citādi nosaki, vai cilvēks ir pilngadīgs. Pārbaudi -1, 17 un 18.

Padoms

Vispirms pārbaudi nederīgu ievadi.

Viens iespējamais risinājums
Python 3
vecums = int(input('Vecums: '))
if vecums < 0:
    print('Nederīgs vecums')
elif vecums >= 18:
    print('Pilngadīgs')
else:
    print('Nepilngadīgs')

3. Punktu vērtējums

Ievadi punktus no 0 līdz 100. 90–100: A, 75–89: B, 60–74: C, zem 60: D. Noraidi vērtības ārpus intervāla. Pārbaudi -1, 59, 60, 74, 75, 89, 90 un 101.

Padoms

Pārbaudi robežas dilstošā secībā.

Viens iespējamais risinājums
Python 3
punkti = int(input('Punkti: '))
if not 0 <= punkti <= 100:
    print('Nederīgs punktu skaits')
elif punkti >= 90:
    print('A')
elif punkti >= 75:
    print('B')
elif punkti >= 60:
    print('C')
else:
    print('D')

4. Biļetes cena

Pamata cena 10 EUR. Bērniem līdz 6 gadiem bez maksas; no 6 līdz 17 gadiem 5 EUR; no 65 gadiem 7 EUR. Pārējiem 10 EUR. Nederīgu negatīvu vecumu noraidi. Papildus: studentiem 18–64 gadu vecumā cena 8 EUR.

Padoms

Vispirms izveido pamata variantu; pēc tam pievieno studenta nosacījumu.

Viens iespējamais risinājums
Python 3
vecums = int(input('Vecums: '))
students = input('Students (j/n)? ').strip().lower() == 'j'
if vecums < 0:
    print('Nederīgs vecums')
elif vecums < 6:
    print('0 EUR')
elif vecums < 18:
    print('5 EUR')
elif vecums >= 65:
    print('7 EUR')
elif students:
    print('8 EUR')
else:
    print('10 EUR')

5. Vienkāršs kalkulators

Ievadi divus skaitļus un operāciju (+, -, *, /). Izdrukā rezultātu, noraidi nezināmu operāciju un pārbaudi dalīšanu ar nulli.

Padoms

Dalīšanas zarā pirms dalīšanas pārbaudi, vai otrais skaitlis nav 0.

Viens iespējamais risinājums
Python 3
a = float(input('a: '))
b = float(input('b: '))
op = input('Operācija (+, -, *, /): ')
if op == '+':
    print(a + b)
elif op == '-':
    print(a - b)
elif op == '*':
    print(a * b)
elif op == '/':
    if b == 0:
        print('Nedrīkst dalīt ar nulli')
    else:
        print(a / b)
else:
    print('Nezināma operācija')

7. Papildu izaicinājumi

De Morgana likumi: not (A and B) ir ekvivalents not A or not B; not (A or B) ir ekvivalents not A and not B. Pārbaudi ar četrām A/B kombinācijām.

match/case (Python 3.10+): piemērots vienkāršai izvēlei pēc vērtības; tā ir strukturālā paraugu atbilstība, nevis vispārējs if aizstājējs.

Python 3
diena = input('Diena: ')
match diena:
    case 'sestdiena' | 'svētdiena':
        print('Brīvdiena')
    case _:
        print('Cita diena')
