Kolekcijas: saraksti, vārdnīcas, korteži un kopas

Vienu vērtību glabā mainīgajā. Daudzu elementu apstrādei lieto kolekcijas: secību list, atslēgu–vērtību saites dict, fiksētu secību tuple un unikālas vērtības set.

Galvenais šodien: list un dict. Korteži — īss obligātais ievads; kopas — papildu materiāls. Interaktīvās demonstrācijas modelē noteiktas Python darbības JavaScript; īsto Python kodu izmēģini savā datorā.

1. Atkārtojums: virknes un cikli

Iepriekš mēs apguvām, kā for apstrādā virkni un kā iegūt atsevišķu simbolu pēc indeksa. Tagad šo pašu ideju izmantosim sarakstiem.

Python 3
text = "Rīga"
print(text[0])     # R
print(text[-1])    # a
for letter in text:
    print(letter)

2. Saraksti: izveide, indeksi un šķēlumi

list jeb saraksts glabā secīgu elementu kolekciju. Saraksts atšķirībā no str ir maināms. Tāpat kā virknē, pirmajam elementam indekss ir 0.

Python 3
fruits = ["ābols", "banāns", "bumbieris"]
print(fruits[0])     # ābols
print(fruits[-1])    # bumbieris
print(fruits[1:3])   # ['banāns', 'bumbieris']
print(len(fruits))   # 3

empty = []
print(len(empty))    # 0

Indeksa piekļuve ārpus robežām izraisa IndexError, bet šķēlums var būt īsāks par pieprasīto diapazonu. Ar for fruit in fruits var apstrādāt katru elementu.

Python 3
for fruit in fruits:
    print("Auglis:", fruit)

if "ābols" in fruits:
    print("Ābols ir sarakstā")
Kā izveidot tukšu sarakstu?

Kāds ir [10, 20, 30][-1]?

Kāds ir [1, 2, 3][0:2]?

Ko dod len(["a", "a", "b"])?

3. Sarakstu modificēšana

Sarakstu var papildināt ar append(), aizstāt elementu pēc indeksa, izņemt pirmo atbilstošo vērtību ar remove() un izņemt pēdējo elementu ar pop().

Python 3
fruits = ["ābols", "banāns"]
fruits.append("plūme")
fruits[1] = "ķirsis"
print(fruits)  # ['ābols', 'ķirsis', 'plūme']
fruits.remove("ābols")
last = fruits.pop()
print(last)    # plūme
print(fruits)  # ['ķirsis']

Svarīgi: append() maina sarakstu un atgriež None. Neraksti fruits = fruits.append("plūme").

4. No teksta uz sarakstu un atpakaļ

split() ir str metode, kas atgriež sarakstu; join() ir str metode, kas savieno virkņu elementus vienā jaunā virknē.

Python 3
text = "Python ir interesanta valoda"
words = text.split()
words[2] = "populāra"
result = " ".join(words)
print(result)  # Python ir populāra valoda

colors = "sarkans,zaļš,zils".split(",")
print(colors)  # ['sarkans', 'zaļš', 'zils']

5. Vārdnīcas: atslēgas un vērtības

dict jeb vārdnīca glabā atbilstību starp atslēgu un vērtību. Sarakstā izmantojam indeksa pozīciju, bet vārdnīcā — mums zināmu atslēgu.

Python 3
student = {"vārds": "Anna", "vecums": 28}
print(student["vārds"])   # Anna
student["vecums"] = 29
student["kurss"] = "Python"

print("vārds" in student)  # True
print(student.get("e-pasts", "nav norādīts"))

for key, value in student.items():
    print(key, value)

student["neesoša"] izraisītu KeyError. Metode get ļauj noteikt noklusējuma rezultātu. in vārdnīcā pārbauda atslēgu. Python vārdnīca saglabā ievietošanas secību.

6. Vārdnīcu praktiska lietošana: vārdu biežums

Katrs vārds būs vārdnīcas atslēga, un reižu skaits būs tā vērtība. Šī ir reāla teksta analīzes pamatoperācija.

Python 3
text = "Rīga Python Rīga dators Python Rīga"
counts = {}
for word in text.lower().split():
    if word in counts:
        counts[word] += 1
    else:
        counts[word] = 1

print(counts)
# {'rīga': 3, 'python': 2, 'dators': 1}

Īsāks ekvivalents cikla iekšienē: counts[word] = counts.get(word, 0) + 1. Vispirms izproti garo variantu, pēc tam īso.

Šeit split() vēl neatdala komatus un punktus no vārdiem. Pieturzīmju normalizāciju var pievienot vēlāk.

7. Korteži un kopas

Korteži (tuple) — īsa obligātā daļa

tuple ir indeksējama, sakārtota, nemaināma secība. Salīdzini ar list, kas ir maināms. Viena elementa kortežam nepieciešams komats.

Python 3
coordinates = (56.95, 24.10)
print(coordinates[0])  # 56.95
print(coordinates[-1]) # 24.1
single = (5,)          # tuple
not_tuple = (5)        # int
# coordinates[0] = 57.0  # TypeError

Kopas (set) — papildu tēma

Kopā ir tikai unikāli elementi, tā nav indeksējama, un elementu iterācijas secība nav garantēta. Tukša kopa ir set(), bet {} ir tukša vārdnīca.

Python 3
names = ["Anna", "Jānis", "Anna", "Ilze"]
unique_names = set(names)
print(len(unique_names))  # 3
print("Anna" in unique_names)  # True
print(sorted(unique_names))   # stabilai izvadei

a = {"Anna", "Jānis"}
b = {"Jānis", "Ilze"}
print(a & b)  # kopīgais: Jānis

1. Iepirkumu saraksts (pamata)

Ievadi produktus līdz komandai beigt un saglabā tos sarakstā. Beigās izdrukā sarakstu un garumu. Testi: uzreiz beigt → 0; ābols, piens, BEIGT → 2; atkārtots produkts paliek sarakstā.

Padoms

Sāc ar items = []; lieto while True, append() un break.

Viens iespējamais risinājums
Python 3
items = []
while True:
    product = input("Produkts (beigt — iziet): ")
    if product.strip().lower() == "beigt":
        break
    items.append(product)
print(items)
print("Skaits:", len(items))

2. Vārdu biežuma skaitītājs (pamata)

Izveido vārdnīcu, kas skaita vārdus ievadītā teikumā. Ignorē lielos burtus. Testi: Rīga Python Rīga → {'rīga': 2, 'python': 1}; tukšs teksts → {}.

Padoms

Pirms cikla counts = {}; ciklā counts[word] = counts.get(word, 0) + 1.

Viens iespējamais risinājums
Python 3
text = input("Teikums: ")
counts = {}
for word in text.lower().split():
    counts[word] = counts.get(word, 0) + 1
print(counts)

3. Pirkumu kopējā cena (pamata)

Doti produkti un cenu vārdnīca; izrēķini kopējo cenu, ieskaitot atkārtotus produktus. ['maize','ābols','ābols','piens'] → 3.90 EUR. Testi arī tukšam grozam un nezināmam produktam.

Padoms

Ar for product in basket atrod cenu vārdnīcā. Pirms piekļuves pārbaudi if product in prices.

Viens iespējamais risinājums
Python 3
prices = {"maize": 1.50, "piens": 1.20, "ābols": 0.60}
basket = ["maize", "ābols", "ābols", "piens"]
total = 0.0
for product in basket:
    if product in prices:
        total += prices[product]
    else:
        print("Cena nav atrasta:", product)
print(f"{total:.2f} EUR")

5. Unikālie vārdi (izaicinājums)

No ['Anna','Jānis','Anna','Ilze'] iegūsti kopu un unikālo vārdu skaitu (3). Papildus: atrod kopīgos vārdus divās kopās.

Padoms

set(names), len() un krustojums &.

Viens iespējamais risinājums
Python 3
names = ["Anna", "Jānis", "Anna", "Ilze"]
unique = set(names)
print(len(unique))      # 3
print(sorted(unique))   # stabilai izvadei
other = {"Jānis", "Marta"}
print(unique & other)   # kopīgais: Jānis
