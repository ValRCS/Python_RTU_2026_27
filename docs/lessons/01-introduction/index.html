Ievads Python programmēšanā

No pirmā print() līdz programmai, kas saņem ievadi un veic aprēķinus.

Šeit redzamās interaktīvās demonstrācijas ir veidotas ar JavaScript, nevis īstu Python interpretatoru. Python programmas raksti un palaid savā datorā.

1. Kas ir Python?

Python ir programmēšanas valoda. Avota kods ir cilvēkam lasāmas instrukcijas, ko rakstām failā ar paplašinājumu .py. Interpretators izpilda Python kodu. Koda redaktors (piemēram, VS Code) palīdz kodu rakstīt, bet pats nav Python interpretators.

Python var izmantot aprēķiniem, datu apstrādei, automatizācijai un tīmekļa lietotnēm.

Kurš rīks izpilda Python programmas kodu?

2. Sagatavo darba vidi

Instalē Python 3 un izvēlies VS Code vai vienkāršāko IDLE. VS Code vajadzīgs Python paplašinājums un pareizi izvēlēts interpretators.

VS Code uzstādīšanas ceļvedis · Python uzstādīšana un problēmu novēršana

Terminālī pārbaudi instalāciju:

Python 3
python --version

Dažās Windows sistēmās izmanto py --version, macOS/Linux — python3 --version.

Izveido failu hello.py, saglabā un palaid to. Pēc katras izmaiņas fails jāsaglabā un programma jāpalaiž atkārtoti.

3. Tava pirmā programma

Funkcija print() izvada vērtības. Teksts jāievieto pēdiņās; aritmētiskas izteiksmes var aprēķināt tieši.

Python 3
print("Sveiki, Python!")\nprint("2 + 2 =", 2 + 2)
Sveiki, Python!
2 + 2 = 4
Ko izvada print(2 + 3 * 4)?

Atvērt pilno hello.py piemēru

4. Mainīgie un datu tipi

Mainīgais ir nosaukums, kas norāda uz vērtību. str ir teksta virkne, int — vesels skaitlis, float — peldošā komata skaitlis. type() palīdz noskaidrot vērtības tipu.

Python 3
vards = "Anna"\nvecums = 30\ncena = 2.5\nprint("Sveika,", vards)\nprint(type(vecums))
Sveika, Anna
<class 'int'>
Kāds ir mainīgā x tips pēc x = "42"?

5. Lietotāja ievade un pārveidošana

input() vienmēr atgriež str. Lai ievadīto tekstu izmantotu kā skaitli, pārveido to ar int() vai float(). Nederīga ievade var izraisīt ValueError.

Python 3
vecums = int(input("Tavs vecums: "))\nprint("Pēc gada:", vecums + 1)

Pamēģini ievadīt arī tekstu, piemēram, abc.

Temperatūras pārvēršanai izmantojam formulu F = C * 9 / 5 + 32.

Python 3
celsijs = float(input("Ievadi °C: "))\nfarenheits = celsijs * 9 / 5 + 32\nprint(f"{celsijs} °C = {farenheits:.1f} °F")

Vecuma aprēķins · Temperatūras pārvēršana

6. Praktiskie uzdevumi

Katru uzdevumu izpildi atsevišķā .py failā savā datorā. Sāc ar vienkāršāko variantu, pēc tam izmēģini papildu iespējas.

  1. Sveiciens: izvada savu vārdu; pēc tam pieprasa vārdu ar input().
  2. 100 gadi: ievadi vecumu un aprēķini, pēc cik gadiem būs 100 gadi. Ja ievadi 30, rezultāts ir 70.
  3. Telpas tilpums: garums × platums × augstums; 4 × 3 × 2.5 = 30 m³.
  4. Temperatūra: pārveido Celsija grādus Fārenheita grādos; 0 → 32, 100 → 212, −40 → −40.
Padoms: kā aprēķināt telpas tilpumu?

Vispirms trīs reizes izmanto float(input(...)), pēc tam sareizini iegūtās vērtības.

Padoms: kāpēc vecuma ievade var neizdoties?

int("abc") nevar pārveidot tekstu par veselu skaitli un izraisa ValueError. Kļūdu apstrādi apgūsim vēlāk.
