1. Kā darbojas tīmeklis

Klients (pārlūks vai Python programma) nosūta pieprasījumu serverim. Serveris atgriež atbildi ar statusu, galvenēm (headers) un, parasti, saturu. HTTP ir saziņas protokols; HTTPS lieto šifrētu savienojumu. URL norāda resursa adresi.

Klients → HTTP GET → Serveris → statusa kods + HTML → Klients

URL piemērs: https://example.com/books?category=python. https ir shēma, example.com ir domēns, /books ir ceļš, category=python ir vaicājuma parametrs. GET parasti pieprasa resursu; POST bieži nosūta datus apstrādei. Šodien izmantojam GET.

4. HTTP pieprasījumi ar Python


Aktivizētā virtuālajā vidē terminālī instalē divas ārējās pakotnes. Colab vai Jupyter izmanto %pip install requests beautifulsoup4 šūnā, ja vajadzīgs. Importa nosaukums Beautiful Soup pakotnei ir bs4.
Terminālis

Python 3
import requests

url = "https://valrcs.github.io/Python_RTU_2026_27/datasets/book_catalog.html"
try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
    print(response.status_code)
    print(response.headers.get("Content-Type"))
    print(response.text[:300])
except requests.RequestException as error:
    print("Neizdevās iegūt lapu:", error)


response.text ir dekodēts teksts, response.content ir baiti. timeout ierobežo gaidīšanu tīkla operācijās, nevis garantē maksimālo kopējo izpildes laiku. raise_for_status() rada HTTPError 4xx/5xx statusam. 200 negarantē vajadzīgo saturu. Ja tīkla nav, turpini ar lokālo failu. Skripts ar rezerves variantu.

5. HTML parsēšana


Parsēšana pārveido tekstu struktūrā, kuru var izpētīt. Beautiful Soup izveido objektu koku no HTML. Izmantojam standarta html.parser, tāpēc nav vajadzīga atsevišķa lxml pakotne.
Python 3
from pathlib import Path
from bs4 import BeautifulSoup

html = Path("datasets/book_catalog.html").read_text(encoding="utf-8")
soup = BeautifulSoup(html, "html.parser")
print(soup.find("h1").get_text(strip=True))
for heading in soup.find_all("h2"):
    print(heading.get_text(strip=True))


Izpildi no kursa repozitorija saknes. find() atrod pirmo elementu vai None; find_all() atgriež atrasto elementu kolekciju, kas var būt tukša. get_text(strip=True) noņem liekas atstarpes no teksta fragmentiem; ja vajag atstarpi starp fragmentiem, lieto separator=" ".

7. Strukturētu datu iegūšana


Vispirms atrodi katru ierakstu (article), pēc tam tā iekšienē meklē laukus. Šādi neveidosies kļūdaini sapāroti nosaukumi un cenas, ja vienam produktam lauks trūkst. Piemēra pilnā funkcija pārbauda arī nederīgas cenas.
Python 3
products = []
for item in soup.select("article.product"):
    title = item.select_one("h2")
    price = item.select_one(".price")
    if title is None or price is None:
        continue
    try:
        amount = float(price.get_text(strip=True))
    except ValueError:
        continue
    products.append({"name": title.get_text(strip=True),
                     "price": amount})
print(products)


Saitēm izmanto link["href"] un urllib.parse.urljoin(), lai iegūtu absolūtu URL. Tabulām vispirms atlasi rindas, tad šūnas. Fiktīvā dzīvokļu tabula.
Python 3
from urllib.parse import urljoin

    print(urljoin(base, link["href"]))

Python 3
import csv
import json

Path("output").mkdir(exist_ok=True)
with open("output/books.json", "w", encoding="utf-8") as file:
    json.dump(products, file, ensure_ascii=False, indent=2)
with open("output/books.csv", "w", encoding="utf-8", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "price"])
    writer.writeheader()
    writer.writerows(products)
with open("output/books.json", encoding="utf-8") as file:
    assert json.load(file) == products
