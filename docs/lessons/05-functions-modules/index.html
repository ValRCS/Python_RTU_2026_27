Funkcijas, moduļi un pirmie testi

No atsevišķa algoritma līdz atkārtoti izmantojamai programmas daļai. Apgūsti def, parametrus, return, lokālos mainīgos un import; pārbaudi savu kodu ar assert.

Šodien svarīgākais: iemācīties pašam uzrakstīt funkciju, kas atgriež rezultātu. Moduļi un testi palīdzēs šīs funkcijas turpmāk izmantot failu, JSON un API piemēros. Pārlūka laboratorijas modelē izvēlētu Python piemēru uzvedību JavaScript — tās nav Python interpretators.

1. Kāpēc vajadzīgas funkcijas?

4. nodarbībā iemācījāmies lietot split(), for un dict.get() vārdu biežuma skaitīšanai. Ja vēlamies to pašu algoritmu palaist desmit dažādiem tekstiem, kodu nevajag kopēt desmit reizes.

Python 3
text = "Rīga Python Rīga"
counts = {}
for word in text.lower().split():
    counts[word] = counts.get(word, 0) + 1
print(counts)  # {'rīga': 2, 'python': 1}

Jaunā ideja: atsevišķu aprēķinu nosaucam, piešķiram tam parametrus, un pēc vajadzības izsaucam to vēlreiz ar citiem datiem.

Ko atgriež {}.get('x', 0)?

Kāpēc veido funkciju no jau strādājoša cikla?

Ko dod 'Rīga Python'.split()?

2. Funkcijas definēšana un izsaukšana

def izveido funkcijas definīciju. Funkcijas ķermenis atrodas atkāpē. Definēšana pati par sevi nesāk ķermeņa darbību — izsaukšanai vajadzīgas iekavas.

Python 3
def greet():
    print("Sveiki, Python!")

def greet_person(name):
    print(f"Sveiki, {name}!")

greet()
greet_person("Anna")
greet_person("Jānis")

Atceries: resnā zarna :, atkāpes un iekavas pie izsaukuma. Kods atrodas Python failā, nevis pārlūka laboratorijā.

Kura ir pareiza funkcijas definīcijas pirmā rinda?

Vai def greet(): ... pati izsauc funkciju?

Kas jāievēro pēc def greet():?

Kurš pieraksts izsauc bezparametru funkciju greet?

3. Parametri un argumenti

Parametrs ir nosaukums funkcijas definīcijā; arguments ir konkrētā vērtība izsaukumā. Vienai funkcijai var būt vairāki parametri.

Python 3
def add(a, b):
    return a + b

result = add(12, 8)
print(result)  # 20

Interaktīvi: izsauc funkciju

Maini argumentus un aplūko, kādas vērtības saņem parametri. Šeit modelējam tieši add(a, b), neizpildot ievadītu Python kodu.

Papildus: noklusēts parametrs def add(a, b=0): ļauj rakstīt add(3). Atslēgvārdu argumenti, piemēram, add(b=8, a=12), var mainīt nodošanas secību.

Kas ir name rindā def greet(name):?

Kas ir 'Anna' izsaukumā greet('Anna')?

Kas notiks, ja add(a, b) izsauc ar add(2) un b nav noklusējuma?

Kāds ir add(3) rezultāts, ja def add(a, b=0): return a+b?

4. Vērtības atgriešana: return un print

print() parāda informāciju ekrānā, bet return nodod funkcijas izsaucējam vērtību un beidz funkcijas izpildi. Ja funkcija nenonāk līdz return, tās atgrieztā vērtība ir None.

Python 3
def double_a(number):
    print(number * 2)

def double_b(number):
    return number * 2

a = double_a(5)     # Izdrukā 10, bet atgriež None
b = double_b(5)     # Atgriež 10, nedrukā
print(a)            # None
print(b + 3)        # 13

Interaktīvi: drukāšana pret atgriešanu

Bieža kļūda: return counts ievietots for cikla iekšpusē pabeigs funkciju jau pirmajā iterācijā.

Ko atgriež print('Sveiki')?

Ko dod result = double_b(5), ja funkcija dara return number*2?

Kas notiek, sasniedzot return?

Kas ir x pēc x = double_a(5), ja double_a tikai izdrukā 10?

Aprēķins atsevišķi no ievades un izvades

Funkcijai padod datus; tā atgriež rezultātu. Izsaucējs lemj, vai datus iegūt no input, faila vai citas funkcijas un vai rezultātu izdrukāt.

Python 3
def calculate_price(price, quantity):
    return price * quantity

price = float(input("Cena: "))
quantity = int(input("Daudzums: "))
total = calculate_price(price, quantity)
print(f"Kopā: {total:.2f} EUR")
Papildus: docstring un tipu anotācijas

Docstring dokumentē funkciju. Anotācijas apraksta paredzētos tipus, bet Python tās automātiski nepārbauda izpildes laikā.

Python 3
def rectangle_area(width: float, height: float) -> float:
    """Aprēķina taisnstūra laukumu."""
    return width * height

print(rectangle_area(3, 4))

5. Algoritms kļūst par funkciju; lokālie mainīgie

Funkcija var gan pieņemt virkni, gan atgriezt vārdnīcu. Izmantosim pazīstamo 4. nodarbības algoritmu.

Python 3
def count_words(text):
    counts = {}
    for word in text.lower().split():
        counts[word] = counts.get(word, 0) + 1
    return counts

print(count_words("Rīga Python Rīga"))
print(count_words(""))  # {}

Funkcijas iekšienē izveidotais counts ir **lokāls mainīgais**. Tāpat funkcija var izsaukt citu funkciju: len(count_words(text)) atgriež dažādo vārdu skaitu.

Python 3
city = "Rīga"

def show_city():
    city = "Liepāja"
    return city

print(show_city())  # Liepāja
print(city)         # Rīga

Interaktīvi: lokālais un ārējais mainīgais

Ko atgriež count_words(''), ja tā sadala tekstu ar split() un skaita vārdus?

Kāpēc return counts nedrīkst ievietot vārdu skaitītāja for cikla iekšpusē?

Kas paliek ārējā city, ja funkcijā lokāli raksta city = 'Liepāja'?

Ko atgriež len(count_words('a b a'))?

Vairākas vērtības: korteža atgriešana un izpakošana

Funkcija var atgriezt vienu kortežu ar vairākām vērtībām. Izpakošana piešķir katru vērtību savam mainīgajam. Piemērs pieņem netukšu sarakstu; tukšai ievadei jāvienojas par atsevišķu rezultātu.

Python 3
def get_statistics(numbers):
    return min(numbers), max(numbers), sum(numbers)

lowest, highest, total = get_statistics([12, 15, 8, 17, 11])
print(lowest, highest, total)  # 8 17 63
Papildus: funkcijas un maināmi saraksti

Lokālais parametrs atsaucas uz padoto objektu. append maina sarakstu; + izveido jaunu sarakstu.

Python 3
def add_in_place(products, product):
    products.append(product)

def with_product(products, product):
    return products + [product]

basket = ["maize"]
add_in_place(basket, "piens")
new_basket = with_product(basket, "ābols")
print(basket)
print(new_basket)

8. Patstāvīgie uzdevumi

20:20–21:05 — 45 minūtes patstāvīgam darbam. Mēģini 1.–3. uzdevumu. 4.–5. ir papildu izaicinājumi. Atver paraugu tikai pēc paša mēģinājuma un pārbaudi risinājumu ar citu ievadi.

1. Vārda noformēšana — format_name(name)

Saņem vārdu, noņem atstarpes un izveido sākumburtu lielu. Testi: " ANNA " → "Anna"; "jĀnis bĒrziņš" → "Jānis Bērziņš"; "" → "".

Padoms: noder virkņu metodes strip() un title().

Viens iespējamais risinājums (atver pēc mēģinājuma)
Python 3
def format_name(name):
    return name.strip().title()

assert format_name("  ANNA  ") == "Anna"
assert format_name("jĀnis bĒrziņš") == "Jānis Bērziņš"
assert format_name("") == ""

title() ir vienkārša formatēšana, ne universāla personvārdu normalizācija.

2. Vārdu biežums — count_words(text)

Iepriekšējo ciklu izveido kā funkciju. Atgrieztās vērtības: "Rīga Python Rīga" → {"rīga": 2, "python": 1}; tukšs teksts → {}.

Padoms: counts = {}, for, get un return ārpus cikla.

Viens iespējamais risinājums
Python 3
def count_words(text):
    counts = {}
    for word in text.lower().split():
        counts[word] = counts.get(word, 0) + 1
    return counts

assert count_words("") == {}
assert count_words("Rīga Python Rīga") == {"rīga": 2, "python": 1}
assert count_words("ābols ābols") == {"ābols": 2}

3. Groza cena — basket_total(basket, prices)

Funkcija saņem produktu sarakstu un cenu vārdnīcu. Tukšs grozs → 0.0; divi āboli → 1.20; iepriekšējais grozs → 3.90.

Padoms: iet cauri katram groza elementam; pieņem, ka visiem ir cenas.

Viens iespējamais risinājums
Python 3
def basket_total(basket, prices):
    total = 0.0
    for product in basket:
        total += prices[product]
    return total

prices = {"maize": 1.50, "piens": 1.20, "ābols": 0.60}
basket = ["maize", "ābols", "ābols", "piens"]
assert basket_total([], prices) == 0.0
assert abs(basket_total(["ābols", "ābols"], prices) - 1.20) < 1e-9
assert abs(basket_total(basket, prices) - 3.90) < 1e-9

5. unittest — papildu izaicinājums

Pārbaudi tukšu tekstu, atkārtojumu un dažādu reģistru. Pēc tam apzināti nomaini sagaidāmo rezultātu un aplūko neveiksmīgo testu.

Testu paraugs
Python 3
# Failam jāatrodas blakus word_tools.py
import unittest
from word_tools import count_words

class WordTests(unittest.TestCase):
    def test_empty(self):
        self.assertEqual(count_words(""), {})

    def test_repeated(self):
        self.assertEqual(count_words("Rīga rīga"), {"rīga": 2})

    def test_single(self):
        self.assertEqual(count_words("Python"), {"python": 1})

if __name__ == "__main__":
    unittest.main()

Savā mapē saglabā test_word_tools.py blakus word_tools.py. Palaid no mapes, kur atrodas word_tools.py un testa fails, ar python -m unittest -v. Savus testus vari palaist arī ar python -m unittest discover -p "test_*.py" -v. Repozitorija gatavie testi pārbauda repozitorija piemēru, nevis tavu atsevišķi izveidoto failu.
